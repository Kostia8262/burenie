# sos-bureniednr.ru — бурение скважин в ДНР

Сайт ИП Пименов Ю. Ю.: бурение и обустройство скважин на воду, Донецк и ДНР.

## Стек

PHP 8 без базы и без сборки. Все запросы идут во фронт-контроллер `site/index.php`,
он разбирает ЧПУ-адрес и подключает страницу из `site/pages/`.

```
site/
  index.php            маршрутизация
  .htaccess            ЧПУ, 301 со старых адресов, кеш, gzip
  robots.txt
  inc/
    config.php         ВСЕ данные сайта: контакты, услуги, города, статьи, FAQ
    helpers.php        e(), u(), ссылки, schema.org
    core.php           геологический разрез (фирменный блок)
    layout.php         <head>, микроразметка, обёртка страницы
    lead.php           приём заявки: лог + письмо + Telegram
    parts/             шапка, подвал, логотип, первый экран, форма
  pages/               по одному файлу на тип страницы
  content/
    services/          тексты услуг
    articles/          тексты статей
    cities/            дополнения к городам (необязательно)
  assets/css|js|fonts|img
```

Чтобы добавить услугу, город или статью, достаточно вписать её в `inc/config.php`
и положить текст в `content/`. Маршрут, меню, карта сайта и перелинковка
подхватятся сами.

## Что нужно заполнить

В `inc/config.php` помечено `TODO`:

- `PRICES_CONFIRMED` и прайс — цифры от заказчика;
- `STATS_CONFIRMED`, `STATS` — лет на рынке и число скважин;
- `LEAD_TG_TOKEN` / `LEAD_TG_CHAT` — если заявки должны падать в Telegram.

Пока флаги выключены, сайт не показывает непроверенных цифр.
